# Source Policy
Class A: official docs, standards, maintainer releases, primary research. Class B: reputable technical publications and vendor case studies. Class C: community/social sources as leads only.

Material claims need source links. High-impact/security claims require primary evidence or independent corroboration. Record publication/retrieval dates. Re-check volatile pricing, limits, model availability and node versions before implementation. Track repository license; public visibility does not imply permissive reuse.

Labels: verified, corroborated, plausible, unverified, contradicted, stale.
