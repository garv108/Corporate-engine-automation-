# Trend Monitoring
Watch AI model/API releases, n8n releases/nodes/templates, MCP and Agent Skills ecosystem, open-source automation repos, security advisories, SaaS connector changes and internal workflow telemetry.

Record title, category, sources, published/detected dates, novelty, relevance, evidence quality, adoption signal, risk, affected capabilities and recommended action.

High-risk changes escalate promptly; routine releases enter weekly review; stale watches are pruned monthly.
