# Workflow QA and Security
Check node/version compatibility, required params, expressions, graph connectivity, type compatibility, least privilege, secret leakage, prompt injection, retries, rate limits, idempotency, error paths, timeouts, PII and data transfer. Return pass/fail, findings, severity, reproducible tests, remediation and release recommendation. Do not approve your own changes; do not claim tests passed unless executed.
